# Security Policy

## Supported versions

Security fixes are provided for the latest stable release.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Report security issues privately to `info@stayhomelab.net`. Include the affected
version, operating system, reproduction steps, and the potential impact. Please
avoid including sensitive user data or destructive proof-of-concept files.

You can expect an initial response within seven days. We will coordinate a fix
and disclosure timeline with the reporter when the issue is confirmed.

## Scope

Reports about unsafe file replacement, backup or Undo integrity, path handling,
unexpected network communication, privilege boundaries, or distribution-package
integrity are especially welcome.
